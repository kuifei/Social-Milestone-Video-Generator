# Phase 0 历史发现

[English](phase0-findings.md) · **中文**

这里保留设计证据，不包含 API 密钥、私有媒体地址或用户素材。

- 原 H3 实验使用主页截图在前、角色三视图在后的参考顺序。当前 H3 Max 改用截图 `image_url`，角色图为单一参考。
- MiniMax H3 在 768P 下生成了带原生音频的 15 秒竖屏视频。
- 提供角色三视图后，身份一致性明显改善，所以流程默认先生成三视图。
- 主要问题是语义错误：页面漂移、文字损坏、角色重复、指向错误和蜡烛动作失败。
- 准确收尾文字应在后期添加，不交给视频模型生成。
- 提示词必须区分右侧 Followers 与左侧 Following。
- 模型参考语法不可通用，所以适配器负责模型专用说明。
- 交付为 1080×1920，2K 尚未证明足够质量收益来抵消费用，因此未设为默认。
- 请求异常必须保留 ID 和错误类别，避免恢复时重复收费。

将角色提取后叠加到原截图上仍是独立实验方向。边缘、阴影、遮挡、动作、延迟和成本完成评估前，不进入主流程。
