# v0.1 Developer Alpha

**English** · [中文](v0.1.0-alpha.1.zh-CN.md)

Release tag: `v0.1.0-alpha.1`. Publish as a GitHub **Pre-release**.

Milestone Video turns an X profile screenshot into a 15-second animated follower celebration. This first developer Alpha runs locally as a TypeScript CLI, using fal for character/video generation and Remotion for a 1080×1920 export with exact closing copy.

- English-first documentation and output; Simplified Chinese closing captions via `--locale zh-CN` (`zh` alias).
- V6 `peace-sign` is the default: avatar exit, empty black avatar circle, follower-count candles, V gesture, and confetti. `blow-out` and custom prompt files are available.
- One paid video request per new job, with recorded estimates and recovery through saved IDs or raw footage. No automatic quality retries.
- Strict options and local export preflight run before generation. Historical jobs retain frozen settings.
- The final [Lauren V6 example](../../examples/lauren/README.md) includes the screenshot, video, reference character, profile, original prompt settings, and a separate media notice.

Known limitations: the model can dim the page, drift text/layout, add cake platters or foot shadows, close the character's eyes, or miss actions. `completed` means exported, not quality-approved. The Lauren example shows these limitations. Its tested Chinese prompt is preserved; the English default translation has local verification but no separate live comparison. Generated results are stochastic.

Costs: static H3 Max estimates are US$1.20 per 15-second video plus US$0.08 for a new character. Reference charges may be additional; actual bills may remain unknown. Profile extraction is a separate paid command.

Install by cloning and following the [README](../../README.md). This is not a standalone npm release. Chinese rendering needs an installed CJK font. X/Twitter is the only platform adapter.
