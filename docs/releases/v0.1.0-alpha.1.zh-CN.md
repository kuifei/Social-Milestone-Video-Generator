# v0.1 开发者 Alpha

[English](v0.1.0-alpha.1.md) · **中文**

发布标签：`v0.1.0-alpha.1`。在 GitHub 标记为 **Pre-release**。

Milestone Video 将 X 主页截图转为 15 秒粉丝里程碑庆祝动画。首个开发者 Alpha 以 TypeScript CLI 在本地运行，通过 fal 生成角色和视频，Remotion 输出带准确收尾字幕的 1080×1920 成片。

- 英文优先的文档和输出；`--locale zh-CN`（兼容 `zh`）支持简体中文收尾字幕。
- 默认 V6 `peace-sign`：走出头像、头像圆内留黑、数字蜡烛、V 手势和彩纸。保留 `blow-out` 和自定义模板。
- 每项新任务提交一次付费视频，记录估算，通过请求 ID 或原片恢复，不因质量自动重试。
- 严格参数及本地导出预检在生成前执行；历史任务保留冻结配置。
- 最后一版 [Lauren V6 示例](../../examples/lauren/README.zh-CN.md)包括截图、成片、角色图、档案、原始配置与独立媒体说明。

已知限制：模型可能让页面变暗、损坏文字或布局、添加托盘和脚下阴影、闭眼或遗漏动作。`completed` 只表示导出，不代表质量通过；Lauren 示例保留了这些缺陷。测试时的中文原提示词已保留，默认英文译本仅做本地检查，尚未单独实测。生成具有随机性。

静态估算：15 秒 H3 Max 视频 US$1.20，新增角色 US$0.08。参考用量可能另计，实际费用可能未知。档案提取为单独付费命令。

按 [README](../../README.zh-CN.md) 克隆运行，尚未发布独立 npm 包。中文渲染需要安装中文字体，目前仅实现 X/Twitter 平台适配器。
