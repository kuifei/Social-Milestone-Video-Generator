# 示例模板

[English](README.md) · **中文**

这些文件是输入格式和提示词模板，其中 Lauren 精选目录包含另有授权说明的公开截图和成片；其他私有测试与凭据仍排除。

| 文件 | 用途 |
| --- | --- |
| `lauren/` | 精选 V6 截图、成片、角色图、复现参数与媒体授权说明 |
| `profile.json` | 使用前修改身份、粉丝数字、头像类别和权利记录 |
| `peace-sign-v6.txt` | 英文 V6，与内置默认对应 |
| `peace-sign-v6.zh-CN.txt` | Lauren 测试使用的中文 V6 原文；用 `--prompt-file` 显式选择可复现其语言 |
| `peace-sign-v4.txt`、`peace-sign-v5.txt` | 历史实验，不是默认效果 |
| `custom-effect.txt` | 简短自定义动作示例 |

`--locale` 独立控制准确收尾字幕，不决定模型提示词的语言。模板本身不证明视觉质量，也不赋予第三方媒体授权。V6 已知缺陷、命令和费用见[主说明](../README.zh-CN.md)。
